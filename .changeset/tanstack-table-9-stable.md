Require stable TanStack Table v9. The `@tanstack/table-core` peer range (for `@nozzleio/mosaic-tanstack-table-core`) and the `@tanstack/react-table` peer range (for `@nozzleio/mosaic-tanstack-react-table`) are now `^9.0.0` instead of `^9.0.0-beta.34`, so v9 beta releases no longer satisfy them. TanStack Table v9 is the npm `latest` release, so install it without the `@beta` tag.
